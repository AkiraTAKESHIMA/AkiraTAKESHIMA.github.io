    　図法によって調整の仕方が異なるが，ひとまず全球でよく使うPlateCarreeと領域でよく使うLambertConformalでよく使う設定を簡単にまとめる． 　例は主にLambertConformalで示すが，PlateCarreeにも同様に適用できる． 　まずインポートと図法の定義をする． 
    import numpy as np
import matplotlib.pyplot as plt
import cartopy.crs as ccrs
from cartopy.mpl.ticker import (
    LatitudeFormatter, LongitudeFormatter,
    LatitudeLocator, LongitudeLocator,
)

PC = ccrs.PlateCarree()

LCC = ccrs.LambertConformal(
    central_longitude=140.0,
    central_latitude=30.0,
    standard_parallels=(60.0, 30.0),
 )

gl.top_labels = False

gl.xformatter = LongitudeFormatter(dms=True, auto_hide=False)

# Right panel -- labels on the left and bottom

# Add new labels on the top

    　class cartopy.mpl.ticker.LongitudeFormatter 　　軸ラベルの形式を制御する．引数が多いので詳細は下のリンクを参照のこと． 　　dms (bool, optional, default=False): Trueのとき，度分秒で表示する．Falseのとき，度を10進数で表示する． 　　auto_hide (bool, optional, default=True): 度や分で同じ値が繰り返されるとき，省略する．dmsがTrueのときのみ有効． 　　number_format (optional, default='g'): 値の書式を指定する．dmsがFalseのときのみ有効． 　+ cartopy.mpl.ticker.LongitudeFormatter — cartopy 0.26.0 documentation 　+ Cartopy map gridlines and tick labels — cartopy 0.26.0 documentation
