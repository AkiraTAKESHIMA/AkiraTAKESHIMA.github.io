座標変換
    Top > Python > 地理空間 (Cartopy)
    手続き
    class cartopy.crs.CRSの持つ手続きを使って投影法間で座標を変換することができる． 　transform_point(x, y, src_crs) 　　src_crsの座標系上の座標(x,y)をこの座標系に変換する．1点のみの変換． 　　src_crs: class cartopy.crs.CRS 　　x, y: float 　transform_points(src_crs, x, y[, z]) 　　src_crsの座標系上の座標(x,y)をこの座標系に変換する．複数の点の変換． 　　src_crs: class cartopy.crs.CRS 　　x, y: numpy配列 　　Return: 　　　shape(x) + (,3)のnumpy配列．最後の次元の1, 2, 3つ目の要素がそれぞれx, y, z座標． 　　　xの形状が(M,N)のとき，戻り値の形状は(M,N,3)で，[:,:,0]がx座標． + cartopy.crs.CRS — cartopy 0.26.0 documentation
    例: 緯度経度座標で定義された日本域の外周線をLCC投影面座標に変換する
    　緯度経度座標を座標系に持つのは正方形図法 (Plate Carrée, 等距円筒図法)． 　これを領域の描画でよく用いられるLCC図法 (Lambert conformal conic projection, ランベルト正角円錐図法) に変換する． 　cartopy.crsにおいて，正方形図法はPlateCarree, LCC図法はLambertComformalで定義される． インポート 
    import numpy as np
import matplotlib.pyplot as plt
import cartopy.crs as ccrs
    図法を定義する 
    PC = ccrs.PlateCarree()

LCC = ccrs.LambertConformal(
    central_longitude=140.0,
    central_latitude=30.0,
    standard_parallels=(60.0, 30.0),
)
    緯度経度座標をLCC投影面座標へ変換する 
    west, east, south, north = 120, 150, 20, 50

points_lon = np.array([west, west, east, east])
points_lat = np.array([north, south, south, north])

points_xyz = LCC.transform_points(PC, points_lon, points_lat)
points_x = points_xyz[:,0]
points_y = points_xyz[:,1]
points_z = points_xyz[:,2]
print(f'xyz shape: {points_xyz.shape}')
    Out: 
    xyz shape: (4, 3)
    LCC投影面に描画する 
    fig, ax = plt.subplots(figsize=(8,5), subplot_kw={'projection': LCC})
ax.plot(
    np.r_[points_x, points_x[0]],
    np.r_[points_y, points_y[0]],
    lw=1, color='k', zorder=1,
)
ax.scatter(
    points_x, points_y,
    s=20, color='r', zorder=2,
)
ax.coastlines(lw=0.5)
plt.show()
